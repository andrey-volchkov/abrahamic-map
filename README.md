# От колыбели к миру

Интерактивная 3D-визуализация в браузере: как на узкой полосе земли между Средиземным морем и
Месопотамией возникли иудаизм, христианство и ислам — и как христианство выросло из явления
одного региона в мировую религию.

Главный приём — **масштаб растёт вместе с религией**. Рельефная карта-макет в проекции Equal Earth
лежит на тёмном столе; в каждом из трёх актов камера отъезжает дальше, а сцена прошлого акта
превращается в светящееся пятно на новой карте.

| Акт | Годы | Масштаб |
|---|---|---|
| I. Колыбель | XII в. до н. э. — VIII в. н. э. | Левант → Восточное Средиземноморье → от Испании до Инда |
| II. Европа | IV — XV вв. | Европа и Средиземноморье, выход в Азию (Церковь Востока) |
| III. Мир | 1492 — сегодня | весь мир |

## Как запустить

Нужен Node.js 20+ (проверено на 22).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # статический сайт в dist/
npm run preview    # посмотреть собранную версию
```

Готовые текстуры рельефа лежат в `public/data/` (≈12 МБ), пересобирать их не нужно. Чтобы
пересобрать с нуля (скачает ≈1500 тайлов высот и слои Natural Earth, 2–3 минуты):

```bash
npm run data
```

Отладочные параметры адреса: `?snap=5` — сразу открыть главу 5 (нумерация с 0),
`?free=1` — свободный режим, `?year=1054`, `?sel=temple70` — открыть событие,
`?v={"lon":35,"lat":32,"dist":900}` — поставить камеру.

### Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает сайт и публикует его при пуше в `main`
(и в рабочую ветку). Если Pages ещё не включены, один раз откройте
**Settings → Pages → Build and deployment → Source: GitHub Actions** и перезапустите workflow.
Сайт использует относительные пути, поэтому работает из подкаталога `/<repo>/`.

## Что сделано

- **Макет мира.** Рельеф и глубины из AWS Terrain Tiles перепроецированы в Equal Earth на трёх уровнях
  детализации (мир ≈8 км/пиксель, Европа и Ближний Восток ≈3 км, «колыбель» ≈1,2 км). Берега, озёра
  и реки — Natural Earth; берег хранится как поле расстояний, поэтому чёткий на любом масштабе.
  Высоты упакованы собственным форматом (предсказание MED + varint + deflate): в два раза меньше PNG.
- **Движок.** Three.js без фреймворка: CDLOD-террейн (квадродерево патчей с морфингом, один instanced
  draw call), суша и «смоляное» море в одном шейдере — отмывка рельефа, cavity-затенение, пустыни и
  зелёные речные долины, цвет моря по глубине, блики, тень берега на воду, «гравировка» вдоль берегов,
  снег по высоте и широте. Торцы макета, стол с мягкой тенью. Постобработка: bloom, tilt-shift, AgX,
  виньетка, зерно, SMAA. Адаптивное разрешение для слабой графики.
- **Зоны влияния.** Из ~300 датированных «очагов» (город или область + дата + радиус) каждый кадр
  рисуется поле по 12 категориям (3 MRT-текстуры в окне вокруг камеры); шейдер террейна
  превращает его в «акварельные» зоны с органичным краем. Штриховкой показана власть халифата там,
  где население ещё не было мусульманским. Точные исторические границы сознательно не рисуются.
- **Маршруты** — ленты, прорисовывающиеся по времени, с бегущей «головой»; дуги для межконтинентальных
  потоков; дорожная сеть Рима; реки.
- **Режим «фильм»:** 27 глав в трёх актах, пролёты камеры по траектории van Wijk–Nuij, титры актов,
  подписи с датами, автопроигрывание; кнопки, колесо, стрелки, пробел.
- **Свободный режим:** таймлайн с полосами актов и отметками всех 149 событий, свободная камера
  (перетаскивание, колесо, правая кнопка — поворот и наклон, жесты на тач-экранах), проигрывание времени.
- **Панель события:** дата, место, пометки достоверности («по преданию», «по священному тексту»,
  «дата приблизительна», «датировка спорна», «предмет веры») и 2–4 предложения.
- **Счётчик доли христиан** — только опубликованные оценки Pew Research Center (1910, 2010, 2020).
- Весь интерфейс на русском; адаптивная вёрстка для телефонов.

## Структура

```
scripts/build-data.mjs     подготовка текстур и векторных слоёв (Node)
public/data/               готовые данные карты
src/data/*.json            содержание: события, главы, маршруты, очаги, подписи, акты, счётчик
src/engine/                рендер: террейн, поле зон, ленты, маркеры, камера, постобработка
src/story/                 модель времени, режимы, управление камерой
src/ui/                    интерфейс
```

Содержание полностью отделено от кода: чтобы поправить текст события или дату появления общины,
достаточно отредактировать JSON в `src/data/`.

## Источники

**Данные карты**
- Рельеф и батиметрия: [AWS Terrain Tiles / Mapzen](https://registry.opendata.aws/terrain-tiles/)
  (SRTM, GMTED2010, ETOPO1, NED и др.; см. [атрибуцию](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)).
- Суша, малые острова, озёра, реки, пустыни (geography regions): [Natural Earth](https://www.naturalearthdata.com/)
  1:10m — общественное достояние.
- Проекция: Equal Earth (Šavrič, Patterson, Jenny, 2018).

**Шрифты** (SIL Open Font License, через Fontsource): Cormorant Garamond, Source Serif 4, IBM Plex Sans.

**Библиотеки**: three.js (MIT), postprocessing (Zlib), fflate (MIT), Vite (MIT), TypeScript (Apache-2.0).
Анимации интерфейса — на встроенном Web Animations API.

**Цифры**
- Pew Research Center, *Global Christianity* (2011): ≈35% христиан в мире в 1910 г. (по Atlas of Global
  Christianity, Johnson & Ross, 2009); доля христиан в Африке южнее Сахары 9% (1910) → 63% (2010).
- Pew Research Center, *How the Global Religious Landscape Changed From 2010 to 2020* (2025): 30,6% (2010),
  28,8% (2020), распределение христиан по регионам.
- SlaveVoyages (Trans-Atlantic Slave Trade Database): ≈12,5 млн человек, отправленных через Атлантику.

**Исторические сведения** — общепринятые в академической литературе даты и формулировки;
спорные датировки и сведения предания помечены. Координаты — современные координаты мест и памятников.
Маршруты Павла восстановлены по книге Деяний и показаны как условные.

## Что стоит улучшить

- **Проверка производительности на реальном железе.** Разработка шла в облаке без GPU (скриншоты через
  SwiftShader); число треугольников невелико (~0,1–0,2 млн), но стоимость фрагментного шейдера и
  постобработки на встроенной графике нужно замерить и, возможно, ввести явные пресеты качества.
- **Тени гор.** Сейчас рельеф читается по отмывке и cavity-затенению; запечённые на GPU мягкие тени от
  хребтов добавили бы глубины на крупных планах.
- **Разрешение рельефа Акта I.** На самых близких планах (Галилея, Иудея) данные 1,2 км/пиксель
  слегка мягкие; можно добавить четвёртый уровень ≈0,4 км для Леванта.
- **Точнее зоны.** Очаги — ручная реконструкция по датам событий; зоны приблизительны. Для Акта III
  можно добавить слой «картина сегодня» по странам на основе табличных данных Pew.
- **Больше глав Акта II–III** (Балканы под властью османов, Эфиопия и Нубия, Латинская Америка XIX в.,
  Китай XX в.) и справочные ссылки к каждому событию.
- **Доступность:** озвучивание глав, режим без анимации (`prefers-reduced-motion`), клавиатурная
  навигация по точкам на карте.
- **Мобильные устройства:** вёрстка адаптирована, но пролёты и шейдеры на телефонах тяжёлые.
